# FinState Analyzer - Document Upload Component

## Supported File Formats
- PDF (.pdf)
- PNG (.png)
- JPEG (.jpg, .jpeg)

## File Size Limits
- Maximum file size: 10MB per file

## Error Codes
- E001: File size exceeds maximum limit
- E002: Unsupported file format
- E003: File appears to be corrupted
- E004: Error processing file

## Features
- Multiple file upload support
- File validation (size, format, corruption)
- Document preview
- Progress tracking
- Batch processing
