# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2024-03-XX

### Added
- OpenRouter API integration for document recognition
- Support for multiple LLM models
- Confidence scoring for extracted data
- Recognition results display in UI
- Retry logic for API calls
- API key configuration in sidebar

### Changed
- Updated document processing workflow
- Improved error handling and messages
- Enhanced preview display with recognition results

### Fixed
- Memory usage optimization for large files
- Error handling for corrupted PDFs
- Preview generation for image files

## [0.1.0] - 2024-02-XX

### Added
- Initial release
- Basic document upload functionality
- PDF and image support
- Simple preview generation
- Basic error handling

### Known Issues
- Limited file size support
- Basic validation only
- No data extraction capabilities
